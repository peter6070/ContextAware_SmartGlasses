# 부품 목록
## 보유 확인
ESP32-CAM 보드, Arduino UNO 호환보드, RGB LED 모듈, 서보모터, DC 모터, 스텝모터와 드라이버, 릴레이 모듈, I2C LCD, 능동 부저, BAR LED, 브레드보드, 점퍼 케이블 및 기타 학습키트 부품. 모든 부품을 사용할 필요는 없습니다.

## 확인 필요
보드·카메라·모듈의 정확한 모델, 핀 배치, 동작 전압·전류, LED 구성과 저항, 모터 기동·정지 전류, 서보 전원, 보유 전원장치와 프로그래밍 어댑터 사양은 미확인입니다.

## 추가 확보 여부 검토
ESP32 프로그래밍용 USB-시리얼 어댑터, 충분한 전원과 케이블, DC 모터에 맞는 드라이버 및 보호 부품은 보유 여부와 모델 확인 후 결정합니다. FAN 속도 조절은 적절한 구동 회로 확보가 전제입니다.
