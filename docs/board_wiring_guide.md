# 보드별 배선 안내

이 문서는 현재 코드에 들어 있는 **시제품 핀 계획**입니다. 보유한 보드와 부품의 정확한 모델, 모듈 극성, 전원 및 구동 회로가 확인되지 않았고 실물 배선도 검증하지 않았습니다. 따라서 아래 핀 번호는 코드에서 확인한 설정이며, 전원선과 부품 단자의 실제 연결은 사양 확인 후 결정해야 합니다.

배선과 변경은 전원을 모두 끈 상태에서 진행합니다. 특히 DC 모터와 서보의 전원을 Arduino 신호 핀에서 공급하지 않습니다.

## 전체 연결

```text
ESP32-S3-CAM ── Wi-Fi 영상 ──> PC ── USB 시리얼 ──> Arduino UNO 호환보드
       │                                                  ├─ RGB LED
       └─ 카메라 커넥터 ─ OV2640                           ├─ 서보모터
                                                          ├─ 모터 구동 회로 ─ DC 모터
                                                          └─ I2C LCD
```

ESP32와 UNO 사이에 GPIO 연결은 사용하지 않습니다. 두 보드에는 각각 전원과 연결 수단이 필요합니다. UNO는 PC와 USB로 연결하고, ESP32의 전원과 업로드 연결은 해당 보드의 USB 커넥터와 사양을 확인해 결정합니다. ESP32 영상을 PC에 전송하는 방식은 Wi-Fi입니다.

## 1. Arduino UNO 호환보드 핀

표의 핀은 [Arduino 펌웨어](../firmware/arduino_controller/arduino_controller.ino)에 작성된 값입니다. I2C의 A4/A5는 **일반 Arduino UNO R3 기준**이므로 사용 중인 호환보드에서도 동일한지 확인합니다. 핀 번호는 커넥터 위치 번호가 아니라 보드에 인쇄된 `D3`, `A4` 등의 이름을 뜻합니다.

| UNO 핀 | 연결 대상 | 역할 | 확인할 사항 |
|---|---|---|---|
| D3 | RGB 모듈의 R 제어 입력 | 빨간색 신호 | 모듈의 R 단자와 전류 제한 회로 |
| D5 | RGB 모듈의 G 제어 입력 | 초록색 신호 | 모듈의 G 단자와 전류 제한 회로 |
| D6 | RGB 모듈의 B 제어 입력 | 파란색 신호 | 모듈의 B 단자와 전류 제한 회로 |
| D9 | 서보의 신호 입력 | 서보 위치 명령 | 신호선 표기와 서보 호환성 |
| D8 | DC 모터 **구동 회로의 제어 입력** | 팬 시작·정지 신호 | 구동 회로 종류, 입력 단자 및 활성 레벨 |
| A4 / SDA | LCD의 SDA | I2C 데이터 | 호환보드의 I2C 핀 배치 |
| A5 / SCL | LCD의 SCL | I2C 클록 | 호환보드의 I2C 핀 배치 |
| GND | 각 회로의 공통 기준 | 신호 기준 전위 | 전원 구성과 절연 여부를 확인한 후 연결 |
| USB | PC의 USB | 코드 업로드 및 PC와 시리얼 통신 | 데이터 전송이 가능한 케이블 및 포트 확인 |

### RGB LED

1. 모듈이 실제로 `R`, `G`, `B` 입력을 제공하는지, 공통 단자가 **공통 음극인지 공통 양극인지**, 또는 별도 전원 단자가 있는 구동 모듈인지 확인합니다.
2. 모듈 회로에 각 채널의 전류 제한 저항이 있는지 확인하고, 없으면 LED 정격과 전원에 맞게 각 채널별 저항을 선정합니다.
3. 적합한 모듈이라고 확인되면 위 표의 D3 → R, D5 → G, D6 → B를 연결합니다. 공통 단자 또는 모듈 전원·접지는 해당 부품의 회로와 정격에 맞춰 연결합니다. 모델이 미확인이므로 이 문서에서는 공통 단자를 5V 또는 GND 중 어느 쪽에 연결할지 확정하지 않습니다.
4. 현재 코드의 `RGB_ACTIVE_HIGH = true`는 임시 설정입니다. 실제 모듈의 켜짐 논리에 맞춰 변경합니다. 현재 코드는 세 채널을 함께 켜고 끕니다.

### 서보모터

| 서보 연결 | 연결 계획 |
|---|---|
| 신호 | UNO D9 |
| 전원 양극 | 서보 정격과 기동·부하 전류에 맞는 전원 양극 |
| 전원 접지 | 서보 전원 접지. 제어 신호의 기준이 같도록 해당 전원 접지와 UNO GND 연결 |

서보선의 색상과 순서는 제품마다 다를 수 있으므로 색상만 보고 판별하지 않습니다. 서보와 전원장치 사양을 확인한 후 전압과 공급 용량을 정합니다. 코드의 닫힘 `0°`, 열림 `90°`는 임시값이며 기구에 무리가 없는 범위를 확인하고 수정합니다.

### DC 모터 팬

| 연결 | 연결 계획 |
|---|---|
| UNO D8 | 검증된 모터 드라이버 또는 스위칭 회로의 **제어 입력** |
| DC 모터 양 단자 | 해당 드라이버의 모터 출력 또는 적합하게 설계한 스위칭 회로 |
| 모터 전원 | 모터와 드라이버의 정격에 맞는 전원 |
| 회로의 신호 기준 | 드라이버 설계에 따라 UNO GND와 모터 구동 회로의 기준 접지 연결 |

모터를 D8에 직접 연결하지 않습니다. 현재 가지고 계신 스텝모터 드라이버나 릴레이가 이 DC 모터와 호환되는지는 확인되지 않았습니다. 사용할 드라이버의 단자명·입력 극성, 모터 기동 및 정지 전류, 역기전력 보호와 전원 인가 시 기본 비활성 상태를 먼저 확인해야 합니다. `FAN_ACTIVE_HIGH = true`도 실제 회로 확인 전 임시값입니다. 팬 속도 조절은 미구현입니다.

### I2C LCD

| LCD 백팩 단자 | 연결 계획 |
|---|---|
| SDA | UNO A4 / SDA — 일반 UNO R3 기준 |
| SCL | UNO A5 / SCL — 일반 UNO R3 기준 |
| GND | UNO와 공통인 GND |
| VCC | LCD 백팩의 **확인된 정격 전압**에 맞는 전원 |

실제 LCD의 모델, 크기, 동작 전압, I2C 백팩과 주소는 아직 미확인입니다. 코드에서는 HD44780 호환 16×2 문자 LCD와 `hd44780_I2Cexp` 라이브러리를 가정합니다. LCD 전원과 SDA/SCL 풀업 전압이 UNO 및 백팩과 호환되는지 확인하기 전에는 VCC를 확정하지 않습니다.

LCD의 `SEL:`은 PC가 선택한 장치이고 `CMD:ON/OFF`는 Arduino가 마지막으로 처리한 명령입니다. 센서가 실제 모터 회전이나 커튼 위치를 측정한 값은 아닙니다.

## 2. ESP32-S3-CAM과 OV2640

카메라의 플랫 케이블을 보드의 카메라 커넥터에 연결하는 구성입니다. **케이블 방향과 커넥터 결합 방법은 실제 보드 설명서를 확인해야 합니다.** ESP32 GPIO에서 UNO, LED, 모터 또는 LCD로 가는 점퍼선은 현재 구성에 필요하지 않습니다.

현재 ESP32 코드에는 Freenove ESP32-S3 WROOM 예제의 카메라 핀 배치가 후보로 들어 있습니다. 이 번호는 **보드와 카메라 사이 내부 연결에 대한 설정**이지 점퍼선을 해당 GPIO에 꽂으라는 뜻이 아닙니다. 구매하신 보드와 동일한지 아직 확인되지 않았습니다.

| 카메라 신호 | 코드의 후보 ESP32 GPIO |
|---|---|
| D0~D3 | 11, 9, 8, 10 |
| D4~D7 | 12, 18, 17, 16 |
| XCLK / PCLK | 15 / 13 |
| VSYNC / HREF | 6 / 7 |
| SCCB SDA / SCL | 4 / 5 |
| PWDN / RESET | -1 / -1 — 코드에서 미사용 |

보드 일치 여부를 확인한 후에만 Wi-Fi 설정 파일에서 `CONFIRM_FREENOVE_CAMERA_PINOUT`을 활성화합니다. 연결과 업로드 설정은 [README](../README.md)를 참고합니다.

## 3. 전원 연결 전 확인 및 코드 설정

1. UNO 호환보드, ESP32-S3-CAM, RGB 모듈, 서보, DC 모터, LCD 백팩의 모델과 단자 표기를 확인합니다.
2. RGB 저항과 극성, 각 부품 전원 전압·전류, 모터 구동 회로와 보호 소자, 접지 구성 및 서보 이동 범위를 확인합니다. 구동 회로·전원이 확보되지 않았다면 해당 부품은 연결하지 않습니다.
3. 전원이 꺼진 상태에서 확인된 배선을 구성하고 단락·극성을 재확인합니다.
4. Arduino IDE에서 `Servo`와 [hd44780 라이브러리](https://github.com/duinoWitchery/hd44780)를 준비합니다. [Arduino 펌웨어](../firmware/arduino_controller/arduino_controller.ino)의 `OUTPUTS_CONFIRMED`, `FAN_DRIVER_CONFIRMED`, `LCD_CONFIRMED`는 모두 기본값이 `false`입니다. 각각 해당 부품의 사양과 배선을 확인한 경우에만 `true`로 변경합니다. `RGB_ACTIVE_HIGH`, `FAN_ACTIVE_HIGH`, 서보 각도와 LCD 크기도 실제 제품에 맞춥니다.
5. 개별 장치를 순서대로 시험합니다. 펌웨어는 아직 컴파일 및 실장치 검증이 완료되지 않았습니다. PC 연결이 끊겨 선택이 해제되어도 기존 출력은 자동으로 꺼지지 않습니다.
