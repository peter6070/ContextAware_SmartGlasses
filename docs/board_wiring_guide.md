# 보드별 배선 안내

이 문서는 현재 코드에 들어 있는 **시제품 핀 계획**입니다. 보유한 보드와 부품의 정확한 모델, 모듈 극성, 전원 및 구동 회로가 확인되지 않았고 실물 배선도 검증하지 않았습니다. 따라서 아래 핀 번호는 코드에서 확인한 설정이며, 전원선과 부품 단자의 실제 연결은 사양 확인 후 결정해야 합니다.

배선과 변경은 전원을 모두 끈 상태에서 진행합니다. 특히 DC 모터와 스텝모터의 전원을 Arduino 신호 핀에서 공급하지 않습니다.

## 전체 연결

```text
ESP32-S3-CAM ── Wi-Fi 영상 ──> PC ── USB 시리얼 ──> Arduino UNO 호환보드
       │                                                  ├─ RGB LED
       └─ 카메라 커넥터 ─ OV2640                           ├─ 서보모터 ─ 커튼
                                                          ├─ 스텝모터 드라이버 ─ 팬
                                                          └─ I2C LCD
```

ESP32와 UNO 사이에 GPIO 연결은 사용하지 않습니다. 두 보드에는 각각 전원과 연결 수단이 필요합니다. UNO는 PC와 USB로 연결하고, ESP32의 전원과 업로드 연결은 해당 보드의 USB 커넥터와 사양을 확인해 결정합니다. ESP32 영상을 PC에 전송하는 방식은 Wi-Fi입니다.

## 1. Arduino UNO 호환보드 핀

표의 핀은 [Arduino 펌웨어](../firmware/arduino_controller/arduino_controller.ino)에 작성된 값입니다. I2C의 A4/A5는 **일반 Arduino UNO R3 기준**이므로 사용 중인 호환보드에서도 동일한지 확인합니다. 핀 번호는 커넥터 위치 번호가 아니라 보드에 인쇄된 `D3`, `A4` 등의 이름을 뜻합니다.

| UNO 핀 | 연결 대상 | 역할 | 확인할 사항 |
|---|---|---|---|
| D3 | 초록색 LED 신호 | 조명 켜기·끄기 | 극성과 전류 제한 회로 |
| D9 | 서보 신호 입력 | 커튼 열기·닫기 | 실제 배선과 전원 확인 |
| D10, D11, D12, D13 | ULN2003 드라이버 IN1, IN2, IN3, IN4 | 팬용 스텝모터 구동 신호 | 드라이버 전원 확인 |
| A4 / SDA | LCD의 SDA | I2C 데이터 | 호환보드의 I2C 핀 배치 |
| A5 / SCL | LCD의 SCL | I2C 클록 | 호환보드의 I2C 핀 배치 |
| GND | 각 회로의 공통 기준 | 신호 기준 전위 | 전원 구성과 절연 여부를 확인한 후 연결 |
| USB | PC의 USB | 코드 업로드 및 PC와 시리얼 통신 | 데이터 전송이 가능한 케이블 및 포트 확인 |

### 초록색 LED

1. 모듈이 실제로 `R`, `G`, `B` 입력을 제공하는지, 공통 단자가 **공통 음극인지 공통 양극인지**, 또는 별도 전원 단자가 있는 구동 모듈인지 확인합니다.
2. 모듈 회로에 각 채널의 전류 제한 저항이 있는지 확인하고, 없으면 LED 정격과 전원에 맞게 각 채널별 저항을 선정합니다.
3. 사용자가 초록색 채널을 D3에 연결했습니다. 공통 단자 또는 모듈 전원·접지는 해당 부품의 회로와 정격에 맞춰 연결합니다. 모델이 미확인이므로 공통 단자를 5V 또는 GND 중 어느 쪽에 연결할지 확정하지 않습니다.
4. 현재 코드의 `LIGHT_ACTIVE_HIGH = true`는 임시 설정입니다. 실제 모듈의 켜짐 논리에 맞춰 변경합니다.

### 28BYJ-48 스텝모터

| 드라이버 연결 | 연결 계획 |
|---|---|
| IN1 / IN2 / IN3 / IN4 | UNO D10 / D11 / D12 / D13 |
| 전원 양극 | 확인된 5V 모터와 드라이버에 적합한 5V 전원 양극 |
| 전원 접지 | 모터 전원 GND와 UNO GND를 공통으로 연결 |

사용자가 팬용 28BYJ-48 5V와 ULN2003 드라이버 연결을 알려주셨습니다. 모터는 드라이버의 모터 커넥터에 연결하며, 기동 전류에 충분한 전원을 사용합니다. 팬 시작 시 계속 회전하고 정지 시 출력을 끕니다. 실물 회전은 아직 검증되지 않았습니다.

### 커튼 서보모터

| 서보 단자 | 연결 계획 |
|---|---|
| 신호 | UNO D9 |
| 전원 양극 | 서보 정격과 부하 전류에 맞는 전원 양극 |
| 전원 접지 | 서보 전원의 GND와 UNO GND를 공통으로 연결 |

서보의 모델, 실제 연결 여부와 전원 사양은 확인되지 않았습니다. 코드의 닫힘 0°와 열림 90°는 시험용 설정이므로, 실제 커튼 기구에 연결하기 전에 방향과 안전한 이동 범위를 확인합니다.

### I2C LCD

| LCD 백팩 단자 | 연결 계획 |
|---|---|
| SDA | UNO A4 / SDA — 일반 UNO R3 기준 |
| SCL | UNO A5 / SCL — 일반 UNO R3 기준 |
| GND | UNO와 공통인 GND |
| VCC | LCD 백팩의 **확인된 정격 전압**에 맞는 전원 |

실제 LCD의 모델, 크기, 동작 전압, I2C 백팩과 주소는 아직 미확인입니다. 코드에서는 HD44780 호환 16×2 문자 LCD와 `hd44780_I2Cexp` 라이브러리를 가정합니다. LCD 전원과 SDA/SCL 풀업 전압이 UNO 및 백팩과 호환되는지 확인하기 전에는 VCC를 확정하지 않습니다.

LCD의 `SEL:`은 PC가 선택한 장치이고 `CMD:ON/OFF`는 Arduino가 마지막으로 처리한 명령입니다. 센서가 실제 모터 회전이나 커튼 위치를 측정한 값은 아닙니다.

## 2. ESP32-S3-CAM과 OV2640

카메라의 플랫 케이블을 보드의 카메라 커넥터에 연결하는 구성입니다. **케이블 방향과 커넥터 결합 방법은 실제 보드 설명서를 확인해야 합니다.** ESP32 GPIO에서 UNO, LED, 모터 또는 LCD로 가는 점퍼선은 현재 구성에 필요하지 않습니다.

ESP-IDF 펌웨어에는 기존 `cam_stream` 프로젝트에서 사용한 ESP32-S3-N16R8과 OV2640의 카메라 핀 배치를 적용했습니다. 아래 번호는 보드와 카메라 소켓 사이의 내부 연결을 나타냅니다. 카메라는 앞서 설명한 소켓으로 연결합니다.

| 카메라 신호 | ESP32 GPIO |
|---|---|
| D0~D3 | 11, 9, 8, 10 |
| D4~D7 | 12, 18, 17, 16 |
| XCLK / PCLK | 15 / 13 |
| VSYNC / HREF | 6 / 7 |
| SCCB SDA / SCL | 4 / 5 |
| PWDN / RESET | -1 / -1 — 코드에서 미사용 |

USB-UART 연결과 빌드 명령은 [ESP-IDF 업로드 안내](esp32_idf_upload.md)를 참고합니다.

## 3. 전원 연결 전 확인 및 코드 설정

1. UNO 호환보드, ESP32-S3-CAM, LED 모듈, 스텝모터 드라이버, 서보와 LCD 백팩의 모델과 단자 표기를 확인합니다.
2. LED 저항과 극성, 각 부품 전원 전압·전류, 모터 구동 회로와 보호 소자, 접지 구성 및 서보 이동 범위를 확인합니다. 구동 회로·전원이 확보되지 않았다면 해당 부품은 연결하지 않습니다.
3. 전원이 꺼진 상태에서 확인된 배선을 구성하고 단락·극성을 재확인합니다.
4. Arduino IDE에서 `Servo`와 [hd44780 라이브러리](https://github.com/duinoWitchery/hd44780)를 준비합니다. [Arduino 펌웨어](../firmware/arduino_controller/arduino_controller.ino)의 `OUTPUTS_CONFIRMED`, `FAN_DRIVER_CONFIRMED`, `LCD_CONFIRMED`는 현재 `true`입니다. `LIGHT_ACTIVE_HIGH`, 서보 각도와 LCD 크기를 실제 제품에 맞춥니다.
5. 개별 장치를 순서대로 시험합니다. 펌웨어는 아직 컴파일 및 실장치 검증이 완료되지 않았습니다. PC 연결이 끊겨 선택이 해제되어도 기존 출력은 자동으로 꺼지지 않습니다.
