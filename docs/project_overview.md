# 프로젝트 개요
## 확정된 목표와 범위
ESP32-CAM 스마트글래스 영상에서 마커를 식별하고 공통 손 제스처로 미니어처 스마트룸 장치를 제어합니다. 대상 선택과 명령을 분리하며 PC가 영상 처리, Arduino UNO 호환보드가 액추에이터 제어를 담당합니다. 초기 마커 ID는 1 LIGHT, 2 CURTAIN, 3 FAN입니다.

MVP는 RGB LED 조명과 서보 커튼을 우선하며 DC 모터 환기는 이후 추가합니다. FAN 속도 조절은 적절한 구동 회로 확보가 전제이며 조명 색상 변경은 선택 사항입니다.

## 미확정
선택 안정화·유지 시간, 제스처 임계값, 성능 목표와 부품별 세부 사양은 실측 후 결정합니다. 이번 단계에서는 동작 기능이 구현되지 않았습니다.
