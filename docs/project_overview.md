# 프로젝트 개요
## 확정된 목표와 범위
ESP32-CAM 스마트글래스 영상에서 마커를 식별하고 공통 손 제스처로 미니어처 스마트룸 장치를 제어합니다. 대상 선택과 명령을 분리하며 PC가 영상 처리, Arduino UNO 호환보드가 액추에이터 제어를 담당합니다. 초기 마커 ID는 1 LIGHT, 2 CURTAIN, 3 FAN입니다.

시제품 제어 대상은 초록색 LED 조명, 서보모터 커튼 및 28BYJ-48 스텝모터 팬이며 I2C LCD에 선택 장치와 명령 상태를 표시합니다. 팬 속도 조절은 아직 구현하지 않았습니다.

추가 목표는 노트북에서 Matter 플러그 Air를 직접 등록·제어하는 것입니다. 스마트폰 앱이나 별도 스마트홈 허브는 사용하지 않으며, 플러그의 통신 방식과 노트북 직접 등록 가능성은 실증이 필요합니다. [Matter 통합 계획](matter_integration_plan.md)을 참고합니다.

필수 요구사항은 가정 외 학술제·공공시설에서도 시연 가능한 네트워크를 확보하는 것입니다. 공공 Wi-Fi가 기기 간 통신을 차단할 수 있으므로 현장 검증과 대체 네트워크 준비를 포함합니다.

## 미확정
선택 안정화·유지 시간, 제스처 임계값, 성능 목표와 부품별 세부 사양은 실측 후 결정합니다. PC·펌웨어 시제품은 작성했으나 실제 장치와 연결한 동작은 검증되지 않았습니다.
