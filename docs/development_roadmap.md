| 1 초기화와 설계 | 완료 | 구조, 골격, 문서와 준비사항 작성 | 파일·문법·문서 일관성 확인 |

| 5 Arduino 제어 | 시제품 작성, 실장치 미검증 | 확인된 회로에서 조명·커튼·환기 제어와 LCD 표시 | 배선 확인 후 명령·오류·구동 검증 |
| 6 통합 | 미착수 | 선택부터 전달까지 연결과 실패 처리 | 선택 변경·연결 손실 포함 종단 시험 |
| 7 시연 | 미착수 | 미니어처와 시연 절차 준비 | 현장 조건 리허설과 안정성 기록 |

## Matter 확장

노트북 단독 플러그 등록·제어는 **설계 단계**입니다. Windows BLE 및 플러그 통신 방식 확인 → 직접 등록·ON/OFF 단독 검증 → 마커·제스처와 LCD 통합 → 네트워크 장애 및 실장치 시연 검증 순서로 진행합니다. 완료 조건과 예외 사항은 [Matter 통합 계획](matter_integration_plan.md)을 참고합니다.

## Phase 2 준비
- ESP32-CAM 보드 및 카메라 모듈 모델, 핀 구성, 프로그래밍 방식과 USB-시리얼 장치 확인.
- 전원 요구사항과 공급 방법, Wi-Fi 환경·접속 방식 확인. 인증 정보는 저장소에 기록하지 않습니다.
- PC 운영체제와 Python 버전, ESP32 보드 패키지 및 라이브러리 호환성 확인.
- 영상 전송 방식과 URL, 해상도·프레임 속도 목표를 실측으로 결정하고 연결 실패·복구 절차를 시험합니다.
