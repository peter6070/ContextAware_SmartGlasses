# 제스처 설계
## 확정된 의미
| 제스처 | 명령 | LIGHT | CURTAIN | FAN |
|---|---|---|---|---|
| 주먹 → 손바닥 | TOGGLE | ON ↔ OFF | OPEN ↔ CLOSE | START ↔ STOP |
| 손바닥 → 주먹 | 다음 동작 준비 | | | |
| 엄지·검지 핀치 | ADJUST | 밝기 | 열림 정도 | 속도(회로 확보 시) |

UNO의 토글 방향은 실행 중 장치별로 마지막으로 응답을 받은 명령에 따라 결정합니다. Matter 플러그는 주먹→손바닥으로 켜고 손바닥→주먹으로 끕니다.

## 상태 머신
안정된 자세 사이의 전환만 명령으로 확정하며 반복 프레임에서는 재발행하지 않습니다. 자세를 0.2초 유지하면 확정하고, 명령 사이에 1초의 쿨다운을 적용합니다. 자세가 0.35초 이상 분류되지 않으면 이전 안정 자세를 초기화합니다.

핀치 거리는 손 크기 기준 길이로 정규화하고 평활화, 변화량 기준과 전송 빈도 제한을 적용하는 방안을 제안합니다. 기준 길이가 너무 작거나 랜드마크가 불안정하면 조절을 보류합니다. 선택 장치가 없으면 명령을 차단하고 선택 변경·해제 시 제스처를 초기화합니다.

안정화 시간과 쿨다운은 실측 전 임시값입니다. 핀치 조절은 설계 단계입니다.
