# 제스처 설계
## 확정된 의미
| 제스처 | 명령 | LIGHT | CURTAIN | FAN |
|---|---|---|---|---|
| 주먹 → 손바닥 | ACTIVATE | ON | OPEN | START |
| 손바닥 → 주먹 | DEACTIVATE | OFF | CLOSE | STOP |
| 엄지·검지 핀치 | ADJUST | 밝기 | 열림 정도 | 속도(회로 확보 시) |

## 상태 머신 제안
손 없음, 불안정, 주먹 안정, 손바닥 안정, 핀치 조절 상태를 구분합니다. 안정된 자세 사이의 전환만 명령으로 확정하고 반복 프레임에서 재발행하지 않으며 쿨다운을 적용합니다. 손 추적이 일정 시간 끊기면 이전 자세와 조절 상태를 초기화합니다.

핀치 거리는 손 크기 기준 길이로 정규화하고 평활화, 변화량 기준과 전송 빈도 제한을 적용하는 방안을 제안합니다. 기준 길이가 너무 작거나 랜드마크가 불안정하면 조절을 보류합니다. 선택 장치가 없으면 명령을 차단하고 선택 변경·해제 시 제스처를 초기화합니다.

안정화 시간, 쿨다운, 손실 시간, 정규화 기준, 핀치 범위 및 필터 계수는 실측 전 미확정입니다. 알고리즘은 구현·검증되지 않았습니다.
